Flow hierarchy — narrow-space clarity experiments

All three are at a real side-panel width (330px). Same data. Which reads clearest? Tweak and re-open.

V1 · Tight tree

Closest to today's structure, just tightened: 13px indent, small pills, code on its own line. Depth is unambiguous, but a 3-level chain still pushes leaves to the right.

V2 · Spine-collapsed

A linear single-child chain (InputView → its one InputSet) stacks as a 2-line header, then the fields list flat at one indent. Removes a whole indent level — the leaves get the width.

V3 · Two-line rows

Each entity is two lines: pill + name, then meta (key, EC) muted below. Names get the full column; meta never competes for width. Taller, but very scannable.
