Command strip — 4 redesign ideas

Complaints addressed: too big, wasted space, unintuitive mode. Each idea kills the two-line layout and the Tab-mystery mode chip in a different way. All shown at the selection on a dark editor.

1 — Verb at send (no mode at all)

One 34px row. You type the instruction first, then pick the intent with the button you press: Ask is Enter, Edit is Ctrl+Enter. The mode concept disappears — intent is chosen last, the way people actually think. Scope is a tiny pill inside the bar; model name lives in its tooltip.

3 — Verb-first palette (progressive)

Ctrl+K opens a two-row chooser (left). Pick a verb — click, arrow keys, or just press A/E — and it collapses into a one-row input with the verb as a removable token (right). Most discoverable for new users; two keystrokes for pros.

4 — Inline native bar (Cursor-style)

No floating box at all: the bar is injected into the editor as an inline widget directly under the selection, full editor width. A 2px purple gutter bracket marks the target lines — that IS the scope badge. Mode is a two-word toggle on the right. Feels like part of the editor, uses all the horizontal space.
